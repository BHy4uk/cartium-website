# cartium-website

Лендинг Cartium: магазин у Telegram, готовий за вечір. Одна страница на украинском,
для владельцев магазинов, которые сейчас продают через директ.

Бриф, проверенные факты и дизайн-решения: [docs/BRIEF.md](docs/BRIEF.md).

## Стек

- [Astro 7](https://astro.build): статическая сборка, ноль JS по умолчанию, оптимизация картинок (AVIF/WebP).
- [GSAP](https://gsap.com) + ScrollTrigger: закреплённые сцены, кинетический заголовок, раскрытие чёрных сцен, скраб.
- [Lenis](https://lenis.darkroom.engineering): плавный скролл (выключается при `prefers-reduced-motion`).
- Шрифт [Fixel](https://github.com/macpaw/fixel) от MacPaw (OFL), урезан до латиницы и кириллицы.
- Иконки [Phosphor](https://phosphoricons.com) (MIT), встраиваются в HTML при сборке.
- Без CSS-фреймворков: токены в `src/styles/global.css`, стили компонентов в самих `.astro`.

## Команды

```bash
npm install
npm run dev       # http://localhost:4321
npm run check     # проверка типов
npm run build     # сборка в dist/
npm run preview   # локальный просмотр сборки
```

Нужен Node.js 22.12+.

## Что где менять

| Что | Где |
|---|---|
| Ссылка на канал (сейчас заглушка) | `src/config.ts` → `CHANNEL_URL` |
| Бот для создания магазина | `src/config.ts` → `BOT_HANDLE`, `SIGNUP_URL` (`?start=connect`) |
| Цены и состав тарифов | `src/config.ts` → `PLANS` (сверено с `billing/plans.py`) |
| Ссылки на документацию и юридические документы | `src/config.ts` |
| Тексты секций | `src/components/*.astro` |
| Цвета, шрифты, радиусы | `src/styles/global.css`: светлая тема в `:root`, тёмная в `:root[data-theme='dark']`, графитовые секции `.stage` |
| Баннеры демо-магазина | `src/assets/banners/` (вырезаны из скриншотов магазина; замените оригиналами с теми же именами) |
| Анимации | `src/scripts/main.ts` |
| Скриншоты продукта | `src/assets/shots/` (сценарий `docshots` из `insomnia.workshop`, см. ниже) |
| Фото демо-товаров | `src/assets/products/` (`tee`, `pants`, `shorts`, `ring`; вырезка кольца: `python tools/ring-cutout.py`) |
| Картинка для превью ссылки | `public/og.png` (1200×630) |

Скриншоты генерируются в продукте сценарием `docshots` (`tools/webapp-harness`) и не содержат реальных данных.
Для сайта они сняты с фото демо-товаров вместо иконок: стенд временно отдавал `src/assets/products/*.png`
на `/__img/tee|jeans|shorts|ring.svg`, затем кадры обрезаны на 196 px сверху **без** скругления углов
(рамку iPhone со статус-баром рисует сам сайт, `src/components/Device.astro`).

Фото демо-товаров сейчас вырезаны из скриншота витрины (около 250 px по ширине). Когда появятся оригиналы,
положите их в `src/assets/products/` с теми же именами, запустите `python tools/ring-cutout.py` и
перегенерируйте скриншоты.

## Структура страницы

1. Hero: крупный заголовок в две строки, при скролле строки расходятся; веер реальных экранов, уведомления о заказах.
2. Оплаты и доставка: LiqPay, plata by mono, Apple Pay, Google Pay, Нова пошта (логотипы в оттенках серого).
3. «Директ против Cartium» на чёрной сцене: два сценария одной продажи играют одновременно, когда секция
   появляется на экране (14 сообщений до 12:49 против оплаченного заказа с ТТН в 10:05), кнопка «Програти ще раз».
4. Студия витрины: настройки раздела «Вигляд» (шаблон, тема, акцент, кнопки, скругление, карточки, шрифт,
   бегущая строка, логотип), покупка в получившейся витрине и заказ в чате бота
   (`src/components/Demo.astro`, `src/scripts/demo.ts`). Подсказка-«коуч» подсвечивает следующий шаг.
5. Запуск за вечер: 4 шага со временем из документации.
6. «Справжні екрани»: переключатель на один экран, список из 10 функций и телефон; листается сам каждые 5 секунд,
   пока посетитель не нажал (`src/components/Showcase.astro`).
7. Инструменты роста с мини-демо: AI-фото (сравнение до/после, 4 реальные операции, фоны и сцены из продукта),
   напоминание о корзине, импорт, пауза checkout, кабинет покупателя.
8. Тарифы с переключателем месяц/год, FAQ, финальный CTA с QR-кодом.

Палитра «М'який графіт»: светло-серая страница, белые карточки, графитовый текст и графитовые секции
(история из директа, тариф Pro, финальный CTA). Есть тёмная тема: по умолчанию как в системе,
переключатель в шапке запоминает выбор (`localStorage`, ключ `cartium-theme`). Цвет есть только внутри
скриншотов. Если включён `prefers-reduced-motion`, закрепления и скраб отключаются.

Маркетинговый контекст для скиллов `marketing-skills`: `.agents/product-marketing.md`.

## Деплой

**Основной сайт: https://cartium.store на Vercel.** Проект Vercel подключён к этому репозиторию:
production собирается из `main`, каждая другая ветка получает свою ссылку-превью. Настройки:
Framework Astro, `npm run build`, папка `dist`, Node 22.x, переменная `SITE_URL=https://cartium.store`.

DNS в Namecheap (Advanced DNS): `A @` и `CNAME www` по значениям из Vercel → Domains,
`TXT _vercel` для подтверждения домена, `CNAME docs → bhy4uk.github.io.` для документации.

**Документация: https://docs.cartium.store**, собирается из репозитория `tgshop-docs` в GitHub Pages
(домен задаёт файл `docs/CNAME` там).

Workflow `.github/workflows/site.yml` на каждый PR и push собирает сайт и проверяет типы, а push в
`main` дополнительно публикует копию на `https://<owner>.github.io/<repo>/`. После переезда на Vercel
её можно отключить: Settings → Pages → Source: None.

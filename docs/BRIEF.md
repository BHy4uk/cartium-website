# Cartium landing: бриф и дизайн-план

Источник фактов: код `insomnia.workshop` (feature_registry, billing/plans, bot/shop_signup_ui,
subscription_lifecycle, docs/ai/*) и публичная документация `tgshop-docs`
(owner-guide, launch, payments, nova-poshta, import, _internal/platform-facts).
Если код и этот файл расходятся, прав код.

## Аудитория

Владельцы небольших магазинов в Украине, которые уже продают через Instagram и Telegram:
одежда, обувь, аксессуары, косметика, хендмейд, товары для дома. Работают с телефона,
не технари. Сегодня заказ у них выглядит как переписка в директе: «ціна в директ»,
размеры, реквизиты, скрин оплаты, ПІБ и отделение, ТТН вручную.

## Главное обещание

Свой магазин внутри Telegram за один вечер: каталог, корзина, оплата картой и ТТН
Новой почты в одном боте. 14 дней бесплатно, карта для старта не нужна.

## Что на сайте не утверждаем

- Лимиты товаров и заказов в месяц: в коде есть, но не применяются и не показываются.
- Количество магазинов, клиентов, оборот, отзывы, логотипы клиентов: данных нет.
- Что покупатель автоматически получает ТТН в чат: не подтверждено кодом.
- Что пробный период включает Pro-функции: trial равен уровню Basic.
- Связь с Telegram как с партнёром. Cartium работает через ботов Telegram, но не аффилирован.

## Дизайн-план

**Design read:** коммерческий лендинг для украинских продавцов (мобильные, не технари),
в «холодной хромовой» эстетике, которая вырастает из хромового логотипа Cartium
и монохромного интерфейса самого продукта. Astro + CSS-токены + GSAP ScrollTrigger + Lenis.

Ручки: вариативность 7, движение 7, плотность 4.

### Цвет

| Токен | Светлая | Тёмная | Роль |
|---|---|---|---|
| `--bg` | `#EEF1F5` frost | `#0B1020` | фон страницы, холодный, без кремового |
| `--surface` | `#FFFFFF` | `#141A2C` | карточки и телефоны |
| `--ink` | `#0E1A2E` | `#E9EEF7` | текст; синий тон из логотипа `#16233B` |
| `--muted` | `#566177` | `#98A3B8` | вторичный текст |
| `--accent` | `#2F4BFF` cobalt | `#6F86FF` | один акцент на всю страницу: CTA, ссылки, выделения |
| `--chrome` | градиент серебра | | рамки телефонов и знак, как у логотипа |

### Типографика

Fixel (MacPaw, Киев, OFL): Display для заголовков, Text для текста. Украинский шрифт
для украинского продукта, полная кириллица. Без моноширинных лейблов и капса.

### Формы

Кнопки и чипы: полная капсула. Карточки: 28px. Телефоны: 46px с хромовой рамкой.
Других радиусов нет.

### Композиция и движение

1. Плавающая навигация-капсула.
2. Hero: текст слева, справа веер из трёх реальных экранов в хромовых рамках,
   наклон за курсором, всплывающее уведомление о новом заказе. Одна сцена загрузки.
3. Главный момент страницы: закреплённая сцена «переписка в директе на 14 сообщений
   сворачивается в одну карточку оплаченного заказа». Движение рассказывает историю.
4. Запуск: 4 шага с таймером, линия заполняется при прокрутке.
5. Горизонтальная галерея экранов продукта (закреплённая на десктопе, свайп на телефоне).
6. Бенто «рост» с живыми мини-демо: фон фото, пауза checkout, напоминание о корзине.
7. Бот и WebApp: два входа в один магазин.
8. Тарифы с переключателем месяц/год, FAQ, финальный CTA с QR-кодом на бота.

`prefers-reduced-motion`: закрепления и скраб отключаются, показываются конечные состояния.

### Самопроверка против шаблонов

- Кремовый фон + засечки + терракота: нет, холодный frost + гротеск + кобальт.
- Тёмный фон + кислотный акцент: нет.
- Три одинаковые карточки фич: нет, галерея экранов и асимметричное бенто.
- Капс-лейблы над каждым заголовком, нумерация 01/02/03 без последовательности: нет;
  номера только у шагов запуска, это реальная последовательность.
- Фейковые скриншоты из div: нет, только реальные экраны из документации.
  Чат в сцене «директ» это иллюстрация переписки, а не имитация интерфейса продукта.
- Длинные тире в видимом тексте: ноль.

# Telegram-канал Cartium: структура и готовые посты

Факты взяты из [BRIEF.md](BRIEF.md), `src/config.ts` и текстов сайта. Если продукт изменится, правьте
сначала `src/config.ts` и бриф, потом посты. Язык канала украинский, как у сайта и бота.

## Зачем канал и как он связан с сайтом

Два входа, один финиш: человек открывает `@cartium_support_bot` и проходит «🛍️ Створити мій магазин».

```
Сценарий 1 (канал)                        Сценарий 2 (сайт)
реклама, репосты, поиск                   cartium.store, живое демо
        │                                          │
        ▼                                          ▼
закреп канала ──► посты-гайды             кнопка «Створити магазин»
        │                                          │
        └──────────► t.me/cartium_support_bot?start=connect ◄──┘
                     (сразу шаг 1 создания магазина)
                                   │
                                   ▼
               после создания: канал = гайды, новости, поддержка
```

- Все «Створити магазин» в канале ведут на `t.me/cartium_support_bot?start=connect`, как на сайте.
  Так человек попадает сразу в шаг 1, без стартового меню бота.
- Сайт ведёт в канал из футера и финального CTA (`CHANNEL_URL` в `src/config.ts`).
  **Сейчас там заглушка**: после создания канала подставьте его адрес.
- Человек с сайта приходит в канал уже с магазином или почти с ним. Закреп должен работать и для него:
  ссылки на инструкцию, `/guide`, поддержку.

## 1. Профиль канала

| Поле | Значение |
|---|---|
| Название | `Cartium · магазин у Telegram` |
| Username | короткий и такой же, как бренд: `@cartium`, `@cartium_store` или `@cartium_ua` (что свободно) |
| Аватар | знак Cartium (хром) на графитовом фоне `#2A2A2E`, без текста: в списке чатов он маленький |
| Описание | текст ниже (лимит 255 символов) |
| Обсуждения | подключить группу для комментариев: вопросы под постами, живые отзывы |
| Реакции | только выбранные: 👍 🔥 ❤️ 🤔 (🤔 честный сигнал «непонятно») |
| Подписи авторов | выключены, канал говорит от имени Cartium |
| Запрет копирования | выключен: посты должны пересылать |

Описание канала:

```text
Власний магазин у Telegram за вечір: каталог, кошик, оплата LiqPay і plata by mono, ТТН Нової пошти.
14 днів безкоштовно.

🛍 Створити магазин: @cartium_support_bot
🌐 cartium.store
```

## 2. Как оформлять посты

**Шаблон любого поста**

```
[эмодзи] **Заголовок одной строкой: польза или боль**

1–2 предложения: ситуация продавца его словами («ціна в директ», «скрін оплати»).

Список из 3–5 пунктов, каждый начинается с одного эмодзи.

Что сделать: одна ссылка или кнопка.

#рубрика
```

**Правила**

- Одна мысль на пост. Если хочется второй, это следующий пост.
- Одна картинка на пост: настоящий скриншот из `src/assets/shots/` в рамке iPhone на графитовом фоне,
  как на сайте. Не стоковые фото, не макеты.
- Эмодзи только в начале строк и всегда одни и те же по смыслу (словарь ниже). Не больше одного на строку.
- Жирным только заголовок и подзаголовки. Курсив и спойлеры не нужны.
- Длинный текст (FAQ, подробности) прячьте в **разворачиваемую цитату** (Expandable quote), тогда пост
  в ленте остаётся коротким.
- Ссылки оформляйте скрытыми: выделить текст → `Ctrl+K` (на телефоне: выделить → Форматування → Посилання).
- Без длинных тире, как на сайте: вместо них двоеточие, точка или `·`.
- Честно про тарифы: если функция только на Pro, так и пишем в посте.
- Никогда: «найкращий», «№1», «безкоштовно назавжди», «без комісії банку», выдуманные цифры и отзывы.
  Отзывы и кейсы публикуем только реальные и с разрешения магазина.

**Словарь эмодзи**

| Эмодзи | Значение |
|---|---|
| 🛍 | создать магазин, витрина |
| 🛒 | каталог, корзина |
| 💳 | оплата |
| 📦 | доставка, ТТН, заказы |
| 📊 | аналитика |
| 🏷 | промокоды, скидки |
| 📣 | рассылки |
| 🎨 | внешний вид магазина |
| ✨ | AI-фото |
| 🔒 | безопасность, токен, деньги |
| 📘 | документация, инструкция |
| 💬 | поддержка, вопросы |
| 1️⃣ 2️⃣ 3️⃣ | шаги |

**Как перенести текст из этого файла в Telegram**

Тексты ниже написаны с разметкой Telegram Desktop: `**жирный**` превращается в жирный при отправке.
`[текст](ссылка)` оформите как скрытую ссылку через `Ctrl+K`. Цитаты (`> `) делаются через меню
форматирования: «Цитата», для длинных включите «Розгортати».

## 3. Рубрики (хэштеги)

Шесть тегов, не больше: чем меньше, тем понятнее. У поста один тег, максимум два.

| Тег | Что внутри | Частота |
|---|---|---|
| `#старт` | что такое Cartium, сколько стоит, как запустить | разово + обновлять |
| `#інструкція` | пошаговые гайды: токен, товары, импорт, оплата, Нова пошта | 1 в неделю |
| `#можливості` | одна функция на пост со скриншотом | 1 в неделю |
| `#продажі` | как продавать больше: корзина, промокоды, рассылки, где поставить ссылку | 1 в неделю |
| `#оновлення` | что нового в продукте | когда есть релиз |
| `#питання` | ответы на вопросы из комментариев и поддержки | раз в 2 недели |

Нажатие на хэштег в канале показывает все посты рубрики, поэтому в закрепе они работают как меню.

## 4. Закреплённый пост

Задача: за 20 секунд ответить на «что это, для кого, сколько стоит, что нажать». Публикуется **текстом,
а не подписью к картинке**: у подписи лимит 1024 символа, у текста 4096.
Картинку даёт превью ссылки `cartium.store` (берётся `public/og.png`): после вставки ссылки нажмите на
превью и выберите «Показати над текстом» и «Збільшити медіа». Получится большая обложка над текстом.

Версия с кнопками (рекомендуется): кнопки под постом крупнее и заметнее ссылок в тексте. Их можно
добавить, если опубликовать пост через бота-администратора канала (например, `@ControllerBot` или
`sendMessage` из любого своего бота с `reply_markup`). Тогда нижний блок со ссылками из текста можно убрать.

```
[ 🛍 Створити магазин ]                 → t.me/cartium_support_bot?start=connect
[ 🌐 Живе демо ]  [ 📘 Інструкція ]      → cartium.store · docs.cartium.store/owner-guide/
[ 💬 Задати питання ]                    → t.me/cartium_support_bot
```

Текст закрепа:


## 6. Регулярные посты после старта

| День | Рубрика | Идея |
|---|---|---|
| Пн | `#інструкція` | один шаг настройки: товары с вариантами, бегущая строка, «Пауза checkout», админы |
| Ср | `#можливості` | один экран продукта: заказы со статусами, клиенты и сегменты, редактор вида |
| Пт | `#продажі` | совет продавцу: как ответить в директе ссылкой, когда делать рассылку, промокод для VIP |
| по факту | `#оновлення` | релизы по шаблону ниже |
| раз в 2 нед. | `#питання` | 3–5 вопросов из комментариев и поддержки |

Запас тем `#можливості` из реальных экранов (`src/components/Showcase.astro`): вітрина як у застосунку,
розміри й кольори варіантами (до 10 фото, закреслена стара ціна), замовлення з фільтрами «Очікують»,
«На перевірці», «До відправки», «У дорозі», клієнти й сегменти (Нові, Повторні, VIP, давно не купували),
магазин у вашому стилі (шаблон, кольори, шрифт, банер, біжучий рядок), «Пауза checkout» на відпустку.

Шаблон `#оновлення`:

```text
**Нове в Cartium: [назва]**

[Одне речення: що тепер можна зробити.]

👤 Для кого: [хто від цього виграє]
📍 Де знайти: [Керування → Розділ → Кнопка]
🏷 Тариф: [Basic / Pro / Business]

#оновлення
```
